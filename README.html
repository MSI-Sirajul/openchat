Core Architectural Highlights

WebRTC Live Voice Calls

Hardware-accelerated peer-to-peer audio calling via stream-webrtc-android. Features progressive call states (Calling → Ringing → Connected Duration Timer), acoustic echo cancellation, noise suppression, and STUN/TURN trickle ICE negotiation.

Sticky Keep-Alive Background Service

24/7 background connectivity powered by OpenChatKeepAliveService running with START_STICKY and typed foreground channels. Auto-recovers after system low-memory pressure or network interruption.

Interactive Push Notifications

Direct Reply actions allow answering incoming chat messages right from the system notification shade. Incoming call channels provide 1-tap Accept/Decline and persistent in-call timer controls.

Global Connectivity Broadcast

Real-time ConnectivityManager.NetworkCallback listening broadcasts system-wide state changes. Instant Material 3 "No Internet Connection" animated banner appears across all screens when offline.

Battery Optimization Whitelisting

Integrated prompt and settings toggle requesting exemption from Android Doze mode (ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS), ensuring calls ring through uninhibited by aggressive OEM battery managers.

Extreme APK Optimization

Configured with R8 full-mode shrinking, ProGuard obfuscation, and strict ABI filtering (targeting armeabi-v7a and arm64-v8a only), eliminating unneeded multi-platform native binaries and slashing download size.

Permissions & Security Rationale

OpenChat employs the principle of least privilege. Every declared permission directly serves an indispensable communication function:

Permission Type Functional Purpose & Rationale
RECORD_AUDIO Runtime Required for capturing outgoing WebRTC microphone audio and recording AAC high-definition voice memos in chats.
POST_NOTIFICATIONS Runtime (API 33+) Enables system heads-up notifications for incoming voice calls, missed calls, and new messages with direct reply action.
REQUEST_IGNORE_BATTERY_OPTIMIZATIONS Special / Intent Exempts the app from aggressive Android Doze kills, guaranteeing real-time delivery of VoIP signaling when the phone is locked.
FOREGROUND_SERVICE Normal Keeps ongoing voice calls and the sticky keep-alive service running without being paused when the user switches apps.
FOREGROUND_SERVICE_MICROPHONE Normal (API 34+) Declared foreground service sub-type for continuous microphone streaming during live VoIP calls.
FOREGROUND_SERVICE_PHONE_CALL Normal (API 34+) Declared foreground service sub-type for VoIP call audio management and notification channel integration.
ACCESS_NETWORK_STATE Normal Allows NetworkMonitor to evaluate Wi-Fi/Cellular connectivity and broadcast offline banners across screens.
INTERNET Normal Enables WebRTC media traffic, Nhost GraphQL queries, real-time WebSockets, and Firebase Push Messaging.
RECEIVE_BOOT_COMPLETED Normal Relaunches the sticky background call listener after the device is restarted.
VIBRATE & WAKE_LOCK Normal Provides incoming call haptic vibration patterns and prevents the CPU from deep-sleeping during active conversations.

Usability & Operation Guide

  1. Account Creation & Authentication

    Launch OpenChat and register with email and password or sign in to an existing account. Secure credentials are encrypted locally with EncryptedSharedPreferences for persistent session recovery.

  2. Battery Optimization & Permissions

    Immediately after sign-in, accept the runtime audio and notification permissions. When prompted, tap "Grant Exemption" to whitelist OpenChat from battery optimization, ensuring you never miss a background call.

  3. Initiating & Receiving WebRTC Calls

    Open any conversation or friend profile and tap the phone icon. The call indicator updates smoothly:

    Calling: Creating local WebRTC offer and pinging recipient.
    Ringing: Recipient's device is vibrating and ringing.
    00:01+: Call connected! Live elapsed duration counter displayed.

  4. Direct Notification Reply & In-Call Controls

    When a message arrives, pull down the Android notification shade and type your response in the "Reply" inline text box without interrupting your current task. For calls, accept or decline directly from the heads-up banner.

  5. Network Offline Detection

    If your cellular data or Wi-Fi drops, OpenChat will instantly show a top banner: "No Internet Connection — Please check your network settings." As soon as connectivity returns, all realtime channels reconnect automatically.

App Optimization & Signature Specs

Gradle Shrinking & Minification Setup:

android {
    defaultConfig {
        ndk {
            // Keep APK lean by packaging only physical ARM architectures
            abiFilters.addAll(listOf("armeabi-v7a", "arm64-v8a"))
        }
    }

    buildFeatures {
        viewBinding = true
        compose = true
    }

    signingConfigs {
        create("release") {
            enableV1Signing = true
            enableV2Signing = true
            enableV3Signing = true
            enableV4Signing = true
        }
    }

    buildTypes {
        release {
            isMinifyEnabled = true
            isShrinkResources = true
            proguardFiles(
                getDefaultProguardFile("proguard-android-optimize.txt"),
                "proguard-rules.pro"
            )
        }
    }
}
